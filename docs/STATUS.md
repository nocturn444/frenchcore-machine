## 4. What the owner needs to do or listen to

Things only the owner can do in GitHub (the agent cannot). Steps in Spanish are in the 0.1.0 security audit, section 10:

- Branch protection of `main` (Settings, Branches): it exists, but its list of required checks is empty and admins can bypass it. Add the required checks `Format check`, `Linux`, `macOS` and `Windows`, and tick "Do not allow bypassing the above settings". Do **not** tick "Require review from Code Owners" (see section 3).
- A tag ruleset for `v*` (Settings, Rules, Rulesets, New tag ruleset): restrict deletions and block force pushes, so a published version tag cannot be moved.
- Enable "Private vulnerability reporting" (Settings, Security), because `SECURITY.md` sends reporters there. Also turn on Dependabot alerts and Dependabot security updates.
- Check Settings, Actions, General: workflow permissions on "Read repository contents and packages permissions", and "Allow GitHub Actions to create and approve pull requests" unticked.
- Decide what to do with the personal email in the first commit (pending with the security review; rewriting the history also means re-creating or withdrawing the 0.1.0 tag and release).
- Optionally, edit the notes of the 0.1.0 release with the known limitations (the text is in `.github/release-notes.md`).
- When the 0.1.1 pull request is merged: start the release (`docs/RELEASING.md`, version `v0.1.1`), check the draft and publish it.

Things to look at and listen to (feedback round):

- Open the latest build of `main` in the Standalone and check the layout against your sketch: box sizes, what is in Global, the free LFO and Other boxes, the EQ display. Resize the window to the smallest and largest and check nothing breaks.
- The amp envelope: the Punch/Tail balance is gone and the Split only divides the kick for the two levels. If the amp envelope still feels wrong, say what you do and what you hear (for example "I move X and Y happens"); I could not find a difference in the envelope itself between your last tested version and now, so I need the symptom.
- The EQ: it now has four free bands. Tell me if you wanted something different (more bands, steeper cuts, a spectrum behind the curve).

Stage 1 of 0.2 (effect copies), to try in the Standalone:

- Open the Effects box: scroll it, press **+ Add effect** and add a second Distortion; it appears as "Distortion 2" at the end, on, with default settings. Try **++** (duplicate) and **x** (remove) on a strip, and drag a strip by its bar. Tell the agent if the buttons are where you want them.
- Load each factory preset and an old project or preset of yours from 0.1: they should sound exactly as before (the tests compare them with the 0.1.1 sound).
- Switch Distortion's Type to Bitcrush: Bits and Rate appear; with any other Type they are hidden.
- Stage 2 (mixer and buses): open the **Mixer** tab. Send Osc 1 to **Bus A**, open the **Bus A** tab, add a Distortion and set **Apply To** to **Tail**: only the tail should be distorted. Try **Punch**, and a Reverb later when it exists. Solo Osc 2 (switch it on first), mute a sound, move Osc 2 alone to Bus B and put an EQ there. Nothing should click when you switch; the bus **Level** at -48 is silence.
- The Noise channel of the mixer comes with the noise oscillator (stage 5).
- Stage 4 (Transient): add a Transient after a Distortion. Raise **Attack** and listen to the punch come back; lower **Sustain** to shorten the tail; move **Speed**. At +100 % the effect is strong on purpose: tell me if you want it gentler or stronger.
- Stage 4 (Filter): add a Filter in Main or on a bus. Try each Type and both Slopes; sweep **Cutoff** while the loop runs (it should not click), raise **Resonance** to a whistle, then **Drive**. Tell me if the ranges or the feel of Resonance and Drive are what you want.
- Stage 3 (EQ): in the EQ strip of Main switch **Extreme** on for a band, give it +30 dB with a high **Q** (30 to 50) around the frequency of your kick's harmonic and listen: it should whistle without clicking or exploding (the safety limiter catches the level). Then raise **Key Track** to 100 % and play different notes: the peak should follow the note one octave per octave. Tell me if the Key Track range or the Extreme limits are what you want.

Tell the agent which ones to drop, rename or replace (after a release, a wavetable can be renamed but not removed or moved, because saved projects refer to its place in the list). Harder ones are louder than the sine at the same Level.
- The Phase 3 envelopes in a DAW or the Standalone: the default "Kick + Bass" amp shape, the pitch drop, the Punch and Tail level knobs. Tell the agent what feels wrong in plain words.

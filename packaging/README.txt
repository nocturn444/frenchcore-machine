Frenchcore Machine {VERSION}
===========================

A wavetable synthesizer for designing frenchcore kicks.

What is in this zip
- VST3: the plugin for most DAWs.
- AU (macOS only): the plugin for Logic Pro and GarageBand.
- Standalone: the plugin as its own program, with an on-screen keyboard.
- LICENSE.txt: the licence.

How to install
https://github.com/nocturn444/frenchcore-machine/blob/v{VERSION}/docs/USER_GUIDE.md#installation

The plugins are not signed, so macOS and Windows warn the first time you open them; the guide
explains the one-time steps. The Linux build needs glibc 2.38 or newer (Ubuntu 24.04 or newer).
